#  Aula Transcrita+IA

Aplicativo web inteligente desenvolvido em Python com **Whisper** e **Gradio** para transcrição e organização de aulas, voltado especialmente para apoiar alunos surdos oralizados.

##  Principais Funcionalidades
- **Transcrição Automática:** Processamento de áudios (via microfone ou upload) utilizando o modelo Whisper.
- **Interface Limpa e Intuitiva:** Desenvolvida em Gradio.
- **Biblioteca de Aulas Salvas:** Listagem explícita e interativa das aulas salvas na pasta persistente, permitindo visualizar o conteúdo completo e realizar o download individual por arquivo.

##  Tecnologias Utilizadas
- **Python**
- **OpenAI Whisper** (Modelo *Tiny*)
- **Gradio**
- **Git & GitHub**

##  Como Executar o Projeto
1. Abra o arquivo do projeto no **Google Colab**.
2. Certifique-se de executar todas as células para instalar as dependências e carregar o modelo Whisper.
3. A interface do Gradio será gerada diretamente no Colab para uso local ou compartilhamento.

##  Futuras Melhorias Mapeadas
- Aperfeiçoamento estético e funcional da interface para maior fluidez.
- Organização e separação avançada por matéria e tema das aulas.
